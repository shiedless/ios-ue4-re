# code of conduct

Discussions and issues here are for learning how these systems work.

- Be respectful. Critique the note, not the person.
- Stay on topic: how things work, corrections, questions.
- No requests for or offers of cheats, bypasses, cracked tools, or offsets for a specific shipping game.
- No harassment, slurs, or personal attacks.

Posts that break these rules get removed; repeat offenders get blocked.

This is a short version of the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), which applies in full.
Report a problem by opening an issue or through GitHub's "Report content" menu.
