# contributing

These are notes, so most contributions are corrections.

- **something in a note is wrong or outdated** → [open a correction](https://github.com/shiedless/ios-ue4-re/issues/new?template=correction.yml). Say which note and section, what's wrong, and how you checked it (device, iOS version, engine build) if it applies.
- **a question, or an idea for a future note** → [Discussions](https://github.com/shiedless/ios-ue4-re/discussions).
- **a typo or a broken link** → a pull request against the note's own repo is fine.

What won't be merged: offsets for a specific shipping game, anything that writes to a game's memory, or anti-cheat bypasses. The notes stop at understanding on purpose.
